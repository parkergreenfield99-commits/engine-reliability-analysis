# CFM56-7B Engine Reliability Analysis

Analysis of 1,419 FAA Service Difficulty Reports to evaluate subsystem reliability, failure severity, and lifecycle behavior in the CFM56-7B engine.

## Key Insight

High-frequency subsystems drive maintenance burden, while low-frequency, high-severity failures dominate regulatory focus.

## Methods

* Failure classification from SDR narratives
* Frequency and severity analysis
* Risk Index (frequency × severity)
* Lifecycle analysis using cycle data
